 ParkEase – Car Parking Booking Website

ParkEase is a responsive car parking booking website built with React. It allows users to search for parking locations, explore available parking spots, and make a demo booking.

  Features

- Search for parking locations
- View sample parking spots and hourly prices
- Select a parking spot
- Enter customer and vehicle details
- Choose parking duration
- View booking cost
- Display a booking confirmation
- Responsive layout for desktop and mobile screens

  Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

 Getting Started

Prerequisites

Install Node.js and npm before running the project.

Installation

1. Clone this repository.

2. Open the project folder in your terminal.

3. Install the dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local address displayed in the terminal.

⚠️ Important Note

ParkEase is a frontend demonstration project. Parking listings use sample data. It does not currently provide real-time parking availability, database storage, online payments, or actual reservations.
